# 隐私说明

本文档说明 RLY/0 Hub（公开仓库）及其闭源组件 RLY/0 Core 在数据处理上的做法。

## 总体原则

**我们不收集、不上传任何用户数据。** RLY/0 Hub 及其闭源组件都不包含任何遥测（telemetry）、埋点统计
或后台上报逻辑；所有账号信息、会话记录、配置和日志，默认只保存在你自己的电脑上。

## 敏感数据的本地加密

- 多账号功能保存的账号快照（如账号别名、关联的凭据引用）、以及中转注入功能保存的中转站 API 密钥，
  在写入磁盘前都会用 **Windows DPAPI**（Data Protection API，绑定当前 Windows 用户账户的加密机制）加密。
- 这意味着这些文件即使被复制到另一台电脑或另一个 Windows 账户下，也无法直接解密读出。
- 加解密均在本机由 rly0-core 完成，密钥不会传输到任何网络位置。

## 网络行为

- **本地代理只监听 `127.0.0.1`**，不会监听 `0.0.0.0` 或任何局域网/公网地址，外部设备无法连接到本机的
  中转代理端口。
- 额度查询、中转站请求等出站网络请求，只会发往你自己添加/配置的目标地址（如 Codex 官方额度接口、
  你添加的中转站 Base URL）；不存在向作者服务器上报使用数据的行为。
- 出站代理仅遵循标准的 `HTTPS_PROXY` / `HTTP_PROXY` 环境变量，不会读取或修改 Windows 系统代理设置。

## 诊断与日志

- “维护工具”页的调试日志导出功能，生成的诊断包**只保存在本机磁盘**，不存在“发送到作者”这类上传按钮或后台逻辑。
- 诊断包在生成时会对已知的敏感字段（如凭据、密钥、账号邮箱等）做脱敏处理；如果你计划把诊断包分享给他人
  排查问题，建议在分享前自行再核查一遍内容。

## 广告位与第三方服务

- “中转注入”页面中的 **RLY/0 · 零号中转**（<https://rly0.com>）推荐位，标注为“作者自营”，可在界面中关闭。
- 该推荐位仅作为一个可选的中转站条目展示，不会读取、上传你添加的其他中转站的密钥或配置；
  是否启用、是否使用完全由你决定。
- 如果你自行添加第三方中转站，请求会按你的配置直接发往该中转站，RLY/0 Hub 与 rly0-core 不会在中间
  额外记录或转发这些请求内容到其他地方。

## 与上游 CodexHost 的关系

RLY/0 Hub 继承自 CodexHost 的功能（多 Harness 宿主、Diff 审阅、Fork 等）在隐私处理上遵循 CodexHost
上游的既有实现；本说明主要补充 RLY/0 Hub 新增功能（多账号、中转注入、维护工具的诊断导出等）的隐私细节。

## 反馈

如果你发现本说明与实际实现不符，或者认为某项行为存在隐私风险，欢迎在仓库中提交 Issue。
